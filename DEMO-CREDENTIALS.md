## How To Use

1. Open `/en/report-crime/verify`.
2. Enter one mock identity ID and request the demo OTP.
3. Enter the matching OTP from this file.
4. Confirm the auto-filled profile details before continuing.

The demo OTP is valid for ten minutes after it is requested and can be consumed once. Request it again to start a new verification attempt.
